24.3.3 #

2026-09-22

⚠️ Security release (stable)

FLAT 24.3.3 is a security release addressing vulnerabilities found in libxml2, libxslt, Symfony/YAML and the Ubuntu 24.04 base image, notably in libcurl and Apache. We encourage all users to update to this release.

New #

  • Documentation: Security Notes about known vulnerabilities

Updated #

  • PHP 8.3.33
  • libxml2 2.13.9: backported security fixes for CVE-2025-10911, CVE-2026-86139, CVE-2026-86142, CVE-2026-86143, CVE-2026-86144
  • libxslt 1.1.43: backported security fixes for CVE-2025-7424, CVE-2025-10911, CVE-2025-11731
  • Symfony Yaml 7.4.18: CVE-2026-45304, CVE-2026-45305, CVE-2026-45133
  • libcurl: CVE-2026-8932
  • Apache: CVE-2026-43951

Removed #

  • PHP extensions not required for production operation: pcntl, pcov, phar, posix, tokenizer, xml

24.3.0 #

2025-11-27

Feature release (stable)

FLAT 24.3.0 is a stable release providing minor updates to third-party libraries and components. It also includes new Swagger properties for Basic Authentication and CORS.

To further increase code quality, some features are now considered deprecated and will be removed in a future release. See the deprecation guide on how to migrate away from them.

New #

  • x-flat-basicauth Swagger property for Basic Authentication
  • max-age property in x-flat-cors to set up CORS caching
  • environment variable $FLAT_STRICT_DEPRECATIONS
  • log level deprecation

Updated #

  • PHP 8.3.28
  • libxml2 2.13.9: CVE-2025-6021, CVE-2025-6170, CVE-2025-7425
  • APCu 5.1.27
  • php-enum 4.7.2
  • raphf 2.0.2
  • Symfony Yaml 7.3.5
  • zipstream-php 3.2.0

Deprecated #

  • auth action
  • regex action
  • other undocumented actions and functions

24.2.0 #

2025-07-08

Feature release (stable)

FLAT 24.2.0 is a stable release bringing new features and some minor component updates. It also includes some code cleanup, bug fixes, and refactoring.

The TLS/SSL configuration provided now disables all TLS versions except 1.2 and 1.3. If you offload SSL processing, e.g. to your load balancer, you should not be affected by this change.

Updated #

  • PHP 8.3.23
  • libxml2 2.13.8
  • Mozilla Server Side TLS 5.7.1
  • psr7 1.8.2
  • phpunit 11.3.6 (test images only)

New #

  • Apache configuration via environment variables
  • environment variable PHPFPM to specify the hostname of the PHP-FPM container
  • xpath attribute in dump action to select which nodes to dump

Fixed #

  • invalid JSON in PHP-FPM logs

Removed #

  • support for TLS 1.1 and earlier for client connections
  • undocumented obsolete features and legacy code

24.1.0 #

2024-11-25

Feature release (stable)

FLAT 24.1.0 features both major and minor updates of its main libraries. Therefore some XML processing behavior changed slightly, see below.

TLS/SSL is now disabled by default in the web server. If you require virtual hosts that can handle TLS/SSL, you now have to set the environment variable SSL to 1. If you are offloading SSL processing, e.g. to your load balancer, you should not be affected by this change.

Updated #

  • PHP 8.3.13
  • libxml2 2.13.5
  • libxslt 1.1.42
  • APCu 5.1.24

New #

  • FLAT’s Swagger dialect now allows example fields directly below request parameters to ease API documentation.
  • switched to modern and more resource efficient event MPM
  • made TLS/SSL optional via SSL environment variable

Fixed #

  • XPath expressions containing non-UTF-8 characters are now considered invalid.
  • XML include elements which could not be resolved are now removed from their document.
  • stabilize TLS tests by badssl test via local container
  • For HTML output, pretty printing is disabled to better match the document structure of the original document.

Removed #

  • unnecessary modules from Apache web server configuration

24.0.0 #

2024-05-14

Major release (stable)

FLAT 24.0.0 features an upgrade of the base image to Ubuntu 24.04 LTS as well as major upgrades of the third-party components PHP and libxml2. Many libraries have received updates, too.

The release also comes with two new images for monitoring (flatphpstats) and maintenance (flatcleancaches) and the option to run web server and PHP-FPM as separate containers.

Updated #

  • Ubuntu 24.04 LTS
  • PHP 8.3.6
  • libxml2 2.12.6
  • APCu 5.1.23
  • pecl_http 4.2.4
  • psr7 1.8.1
  • xmlseclibs 3.1.1
  • Symfony Yaml 7.0.3
  • ZipStream-PHP 3.1.0

New #

  • optionally run PHP-FPM and httpd as separate containers
  • flatphpstats container image to monitor utilization
  • flatcleancaches container image
  • psr 1.2.0

Changed #

  • /test.fit endpoint now requires parameter ?full for detailed output: /test.fit?full
  • the access log output of Apache httpd is now formatted as JSON
  • consolidated field names in logs

Removed #

  • Console_CommandLine
  • http-factory
  • message-factory
  • PEAR
  • php-enum
  • PSR Http Message
  • undocumented features/legacy code, e.g. automatic cookie forwarding, control scripts, …
